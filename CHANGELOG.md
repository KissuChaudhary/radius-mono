# Changelog

## 1.000 — 2026-11-13

First release.

- Roundness axis `ROND` 0–100 (default 100) on top of JetBrains Mono 2.304's `wght` 100–800.
- Upright and Italic variable fonts (TTF + WOFF2) and 16 static TTFs at ROND 100.
- All 153 code ligatures and 35 OpenType features preserved; cell-boundary joins kept sharp.
